# 行为特征拆解与验证

行为特征不是人格测评，也不能从简历中的形容词直接得出。目标是形成可验证的工作行为假设，并用多道问题寻找一致或矛盾证据。

## 行为证据链

每项行为特征按以下六列输出：

| 字段 | 含义 |
|------|------|
| 行为假设 | 可能存在的、与岗位有关的工作行为 |
| 简历信号 | 触发该假设的原文或经历 |
| 替代解释 | 同一信号还可能由什么造成 |
| 验证问题 | 要求真实、近期、具体事例 |
| 正向信号 | 可观察且可复述的行为证据 |
| 红旗信号 | 回避、归因、矛盾或缺失的证据 |

例：简历写“主导跨部门项目”，不能直接判定“影响力强”。替代解释可能是名义负责人、依赖职位权力或团队已有共识。需要追问其在无汇报关系、存在反对意见时如何推进。

## 八类核心行为

### 主动性与主人翁意识

- **简历信号**：从 0 到 1、主动发起、建立机制、超出职责解决问题。
- **验证问题**：讲一个没有人要求你做、但你认为必须做的事情。你为何介入？承担了什么风险？
- **反证追问**：有没有你选择不介入的问题？为什么？
- **正向信号**：主动界定问题、争取资源、承担后果，也能判断边界。
- **红旗信号**：把“加班多”当主人翁；越权但不沟通；所有例子均由上级指派。

### 结果导向与闭环

- **简历信号**：有目标、结果指标、上线/交付、复盘和后续改进。
- **验证问题**：讲一个你投入很大但最终未达目标的项目。你何时知道会失败？做了什么？
- **反证追问**：如果去掉团队和品牌资源，你的个人贡献还剩什么？
- **正向信号**：能说明基线、目标、实际结果、归因与复盘。
- **红旗信号**：只描述活动量；数字无口径；失败全部归因外部。

### 结构化问题解决

- **简历信号**：复杂故障、模糊问题、诊断、建立模型或排查框架。
- **验证问题**：讲一个起初定义错误的问题。你如何发现并重构问题？
- **反证追问**：你排除过哪些看起来最可能但最终错误的假设？
- **正向信号**：区分事实与假设，按信息价值排序验证。
- **红旗信号**：直接跳到熟悉方案；无法解释为何选择验证顺序。

### 学习敏捷性

- **简历信号**：跨领域、快速承担新职责、掌握新工具并产生成果。
- **验证问题**：最近一年最难学的东西是什么？第一次尝试哪里错了？
- **反证追问**：讲一个你学习后仍未掌握或决定放弃的领域。
- **正向信号**：有具体学习策略、反馈循环和迁移成果。
- **红旗信号**：只列课程证书；声称“很快学会”但无失败和应用。

### 协作与影响力

- **简历信号**：跨部门、无权威影响、多方协调、客户/高管沟通。
- **验证问题**：讲一个关键利益相关方明确反对你的案例。你如何理解其立场并推进？
- **反证追问**：对方最终是否真的改变？还是被上级拍板？
- **正向信号**：识别利益差异、调整沟通方式、建立共同目标。
- **红旗信号**：把升级上报当主要影响方式；贬低反对者；只在有权力时推进。

### 质量、判断与风险意识

- **简历信号**：审查、质量体系、安全、合规、关键决策、止损。
- **验证问题**：讲一个速度与质量冲突的真实案例。你如何确定可接受风险？
- **反证追问**：有没有你坚持过度、后来证明应该更快的例子？
- **正向信号**：能分级风险、设置护栏、记录决策并根据新证据调整。
- **红旗信号**：永远选质量或永远选速度；无法定义风险阈值。

### 反馈、冲突与自我认知

- **简历信号**：管理、协作、复盘、组织变化、长期合作。
- **验证问题**：最近一次收到的具体负面反馈是什么？你做了什么改变？
- **反证追问**：谁会认为你没有真正改变？为什么？
- **正向信号**：反馈具体、有情境、有行为改变和后续验证。
- **红旗信号**：把优点包装成缺点；反馈对象不可核实；强调对方误解。

### 韧性与压力管理

- **简历信号**：危机、资源受限、失败恢复、长期高压交付。
- **验证问题**：讲一个持续数月、结果不确定的困难阶段。你如何维持判断和团队状态？
- **反证追问**：压力下你最容易出现什么负面行为？如何被别人观察到？
- **正向信号**：主动排序、寻求支持、调整计划、保护关键质量与团队。
- **红旗信号**：把长期透支当韧性；否认压力影响；对团队情绪缺乏觉察。

## STAR-L 追问顺序

1. **Situation**：时间、背景、规模、约束。
2. **Task**：候选人的明确责任与成功标准。
3. **Action**：候选人本人做了什么，关键决策是什么。
4. **Result**：结果、基线、指标、未达成部分。
5. **Learning**：之后改变了什么，下一次如何应用。

每个行为至少获取两个不同情境的证据，并做一次反证追问。单一案例不足以定性。

## 证据强度

- **A 强证据**：近期具体案例，个人行动清晰，有结果/反馈，可被进一步核验。
- **B 中证据**：案例具体但结果或个人贡献不完整。
- **C 弱证据**：泛化观点、假设性回答、团队成果无法归因。
- **D 反向证据**：回答与简历矛盾、回避关键细节、将责任持续外归。

输出行为结论时写成：“在 X 情境下表现出 Y 行为，证据等级 B；仍需在 Z 情境验证。”不要写成永久人格结论。
