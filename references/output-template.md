# 输出模板

最终输出按以下结构组织，可直接用于面试执行。语言与用户输入一致（默认中文）。

## 1. 岗位与候选人概览

- 岗位：一句话概括 JD 核心要求
- 候选人：一句话概括背景
- 面试类型 / 侧重：商务 / 业务 / 研究 / 开发 + 额外要求

## 2. 简历四维拆解

四个维度分别列出并排序（见 `resume-breakdown-framework.md` 的输出格式）：

### 技能 Skills
### 经验 Experience
### 行为特征 Behavioral traits
### 业务影响 Business impact

每项标注证据等级（[陈述] / [推断] / [缺失]）。

## 3. 匹配评估

- 逐条对照 JD 的 must-have / nice-to-have，给出匹配等级（强匹配 / 部分匹配 / 缺失 / 存疑）与依据
- 整体匹配度：分数 + 一句话结论
- 优势
- 缺口
- 风险点
- 结论：是否建议进入下一轮 + 面试重点

## 4. 关键面试提问

按维度组织，每题标注：考察目的、期望信号（好答案）与红旗信号（坏答案）。

### 技能类提问
### 经验类提问
### 行为特征类提问
### 业务影响类提问
### 缺口 / 风险验证提问

## 5. 面试流程

分轮列出：轮次、目标、面试官角色、时长、考察维度、通过标准。

## 6. 额外要求（如有）

如 coding 题、系统设计题、英语验证等，按对应 reference 的格式补充。

## 7. 来源引用

如涉及外部题目（LeetCode 等），列出题号与链接。
